# Strata for gfx906

This fork makes Strata's prompt processing faster on AMD gfx906 cards (Instinct MI50 / MI60, Radeon VII) and adds
IQ4_NL expert support there. Generation speed stays the same. Everything else is upstream
[Strata](https://github.com/Niko1221/Strata), currently v0.1.45, merged in as upstream releases.

## Results

Qwen3.8-Flash-Next, Swift 1.5 GGUFs, MI50 32 GB cards, `--prefill 4096`, 3 prompts per context length.

| IQ3_S, 2 GPUs | 8K | 526 / 57.4 | **699** / 58.4 (+33%) |
| | 32K | 709 / 58.0 | **925** / 60.8 (+30%) |

Upstream is the stock gfx906 build: v0.1.45 on 2 GPUs, v0.1.41 on 3 GPUs (the two measured the same on 2 GPUs).

## What changed

- **Repacked expert GEMM.** The MoE expert products of the prompt run through a repacked int8 GEMM, adapted from
  [mx-llama.cpp](https://github.com/mxxm-t/mx-llama.cpp) (MIT, vendored in `src/prefill/rp/`). Covers IQ4_NL, IQ3_XXS
  and IQ3_S experts, with results bitwise equal to the MMQ path it replaces.
- **Dense projections in int8.** The dense prompt projections run through int8 MMQ, or the repacked GEMM where it has
  the type (Q8_0, Q5_K, Q6_K, IQ4_NL, IQ4_XS). K and V stay FP16, which keeps the draft head's acceptance rate.
- **FP16 prompt GEMMs.** Upstream's `STRATA_HIP_PROMPT_F16` is on by default here.
- **IQ4_NL experts.** IQ4_NL gate/up experts load on gfx906.
- **Build fixes** for the gfx906 build, two of them from
  [cassettesgoboom/strata-gfx906](https://github.com/cassettesgoboom/strata-gfx906).

Also in this fork, not gfx906-specific: the opt-in run-config option `system_to_user`. Lines of the system message
that change between requests, such as a client's date and time, move to the user message, so new chats reuse the
cached system turn. See the comment in `serve/frontend.py`.

## Running

```sh
docker run --rm --device=/dev/kfd --device=/dev/dri --group-add video --ipc=host --ulimit memlock=-1 \
  -p 8080:8080 -v /path/to/models:/models:ro -v /path/to/data:/data -v ./config.json:/config/active.json:ro \
  ghcr.io/janus-reith/strata-gfx906:latest
```

The image runs Strata's server with the run config at `/config/active.json`;
[`docker/gfx906/example-config.json`](docker/gfx906/example-config.json) is the 2-GPU IQ3_S config measured above.
The pack and the MTP draft head are prepared with the tools in the image (`tools/iq_pack.py`, `tools/mtp_*.py`), as
described in [docs/AMD_HIP.md](docs/AMD_HIP.md). To build the image yourself:
`docker build -f docker/gfx906/Dockerfile -t strata-gfx906 .`

## Switches

All on by default in the gfx906 build; set one to `0` to turn that part off.

| variable | part |
|---|---|
| `STRATA_PF_RP` | repacked expert GEMM |
| `STRATA_DENSE_MMQ` | dense projections through int8 MMQ |
| `STRATA_DENSE_RP` | dense projections through the repacked GEMM |
| `STRATA_MMQ_KQ` | K-quant MMQ kernels for dense Q5_K / Q6_K |
| `STRATA_HIP_PROMPT_F16` | FP16 prompt GEMMs |
